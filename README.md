# Temperature Visualizer: A webapp to visualize temperature data from crab tanks.

## Project Structure
### Backend
Contains FastAPI routes and file fetching logic, and csv merging logic.
### Frontend
Contains HTML and JS to visualize the merged csvs.

## Quick Start
First create virtual environment for python backend and run uvicorn server for API. Then run liveserver from vscode extension to run frontend.

## Requirements
- Python

## How to Run
### Frontend
Run index HTML file with live server extension from vscode.
### Backend
Create venv and install dependencies. Then run uvicorn server from the backend directory. (For more detailed instructions see README.md in the backend directory).
